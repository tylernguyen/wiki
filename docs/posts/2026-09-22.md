# 2026-09-23

![Zensical](https://assets.tylernguyen.wiki/logos/Zensical.webp){ .twemoji } [Zensical v0.0.64 :lucide-arrow-up-right:](https://github.com/zensical/zensical/releases/tag/v0.0.64) now includes `blog` plugin support.

Previously, _Dot Wiki_ used :simple-materialformkdocs:{ .materialformkdocs } [Material for MkDocs (Insiders) :lucide-arrow-up-right:](https://github.com/squidfunk/mkdocs-material). Zensical is the successor project by the same author.

Now that `blog` plugin support has been shipped, expect to see more frequent posts to this blog.
